# Ответы на вопросы
### 1) Как получить ссылку на текущий поток?
Для получения ссылки на текущий поток можно использовать метод `Thread.currentThread()`. \
Пример:
```
Thread currentThread = Thread.currentThread();
System.out.println("Current thread: " + currentThread.getName());
```
### 2) Зачем нужно ключевое слово synchronized? На что его можно вешать?
Ключевое слово synchronized в Java используется для синхронизации потоков.
Им помечается определённый кусок кода, который может выполняться только одним потоком одновременно. \
`Synchronized` можно применять к:
- **Методам**: Для синхронизации доступа к объектным методам.
- **Статическим методам**: Для синхронизации на уровне класса.
- **Блокам кода**: Для синхронизации произвольного кода на заданном объекте.

### 3) Захват какого монитора происходит при входе в synchronized метод/статик метод/блок?
- **Метод экземпляра**: Захватывается монитор текущего объекта (`this`).
- **Статический метод**: Захватывается монитор класса (`ClassName.class`).
- **Блок**: Захватывается монитор указанного объекта (`object`).

### 4) Зачем нужно ключевое слово `volatile`?
`Volatile` используется для указания, что значение переменной может быть изменено несколькими потоками. \
Оно гарантирует, что изменения, сделанные в одном потоке, сразу же доступны для чтения в другом потоке. Иными словами, любой поток всегда видит последнее значение переменной volatile. \
Применяется **только к полям** (переменным экземпляра или класса). Нельзя использовать с методами, конструкторами или классами.  

### 5) Что делают методы `Object#wait`, `Object#notify`, `Object#notifyAll`?
- `wait()`: Останавливает текущий поток и переводит его в состояние ожидания на объекте, пока другой поток не вызовет `notify()` или `notifyAll()`.
- `notify()`: Пробуждает один поток, ожидающий на данном объекте.
- `notifyAll()`: Пробуждает все потоки, ожидающие на данном объекте. \
Все эти методы вызываются только из синхронизированного контекста — синхронизированного блока или метода.

### 6) Что за исключение `IllegalMonitorStateException`?
`IllegalMonitorStateException` — это исключение времени выполнения в Java, которое возникает в многопоточных приложениях.
Оно указывает на то, что вызывающий поток попытался дождаться монитора объекта или уведомить другие потоки, ожидающие на этом мониторе, без владения указанным монитором. \
Исключение возникает, если один из методов wait(), notify() или notifyAll() класса Object вызывается вне синхронизированного блока или метода.

### 7) Что делает метод `Thread#join`?
Метод `join` позволяет одному потоку ждать завершения другого.  

### 8) Что делает метод `Thread#interrupt`?
Метод `interrupt` устанавливает флаг прерывания у потока. Если поток находится в состоянии ожидания (`sleep`, `wait`, `join`), он выбрасывает `InterruptedException`. \
При этом сам вызов этого метода НЕ завершает поток, он только устанавливает статус: в частности, метод `isInterrupted()` класса `Thread` будет возвращать значение `true`.
